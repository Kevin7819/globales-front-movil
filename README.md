# Globales Front Móvil 📱

Proyecto móvil construido con **React Native + Expo**.

## Requisitos

- [Node.js](https://nodejs.org/) (versión LTS recomendada)
- [Expo CLI](https://docs.expo.dev/get-started/installation/) (`npm install -g expo-cli`)
- App [Expo Go](https://expo.dev/client) en tu celular para probar la aplicación.

## Instalación

Clona el repositorio y dentro de la carpeta ejecutá:
npm install

Correr el proyecto

Iniciá el servidor de desarrollo:

npm start


Luego escaneá el QR con la app de Expo Go en tu celular.
